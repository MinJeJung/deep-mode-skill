# 적용 예시

입력: `/깊게 Claude Code 서브에이전트 기능을 기업 교육 강의안 1차시로 정리해줘`

## 1단계

**작업 유형**: 강의안·교육 자료 (보조: 리서치·팩트체크)

1. **전문가 관점**: 수강생이 직접 만들어 보는 실습을 넣는다. 기능이 바뀌는 속도가 빠르므로 문서 확인 날짜를 강의안에 적는다.
2. **원자료**: Claude Code 공식 문서의 subagents 페이지 — docs.claude.com. 기존 강의 자료 — 강의 자료 폴더의 관련 노트.
3. **방법론·도구**: 브라우저로 공식 문서 원문을 직접 읽고, 차시 구성 템플릿으로 정리. 배제: 블로그 요약 글 — 버전이 오래되었을 수 있음.
4. **객관적 검증**: 실습 단계를 현재 설치된 Claude Code에서 직접 실행해 서브에이전트 파일 생성과 호출을 확인. 기능 설명은 공식 문서 문장과 대조.
5. **완료 기준**: 학습 목표 3개, 실습 1개 이상, 소요 시간 합계 = 차시 시간. 실습이 실제로 실행됨. 공식 문서 확인 날짜 기재.

## 2단계

```text
[목표] 기업 실무자가 Claude Code 서브에이전트를 직접 만들고 쓸 수 있게 하는 1차시(60분) 강의안
[산출물] md 강의안 — 저장: 강의 자료 폴더
[먼저 확인할 원자료]
- Claude Code 공식 문서 subagents 페이지 (원문 직접 읽기)
- 기존 Claude Code 강의 노트
[방법·도구]
- 공식 문서에서 정의·파일 위치·호출 방법 추출
- 차시 구성 템플릿으로 도입 10분 / 개념 15분 / 실습 30분 / 정리 5분 구성
[검증 절차]
- 실습 단계를 로컬 Claude Code에서 그대로 실행
- 기능 설명 문장을 공식 문서와 1:1 대조
[완료 기준]
- [ ] 학습 목표 3개 (행동 동사)
- [ ] 실습 실행 확인
- [ ] 시간 합계 60분
- [ ] 문서 확인 날짜 기재
[범위 밖] 슬라이드 제작, 다른 차시 작성
```

## 3단계

비용·외부 영향이 없고 `--확인`도 없으므로 바로 실행한다.

## 4단계 (보고 형식 예)

**결과**: 1차시 강의안 완성 — `<저장 경로>`

**실행한 검증**
- 실습 실행: 로컬에서 서브에이전트 파일 생성 후 호출 → 정상 동작
- 문서 대조: 기능 설명 6문장을 공식 문서와 대조 → 6/6 일치

**완료 기준**
| 기준 | 상태 | 근거 |
|---|---|---|
| 학습 목표 3개 | 충족 | 강의안 1절 |
| 실습 실행 확인 | 충족 | 위 실행 결과 |
| 시간 합계 60분 | 충족 | 10+15+30+5 |
| 문서 확인 날짜 | 충족 | 강의안 머리말 |
