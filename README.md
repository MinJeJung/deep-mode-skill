# /깊게 — 심층 모드 스킬

AI 에이전트에게 일을 시키기 전에 **"전문가라면 무엇을 먼저 확인할까"** 를 스스로 답하게 하는 스킬입니다. Claude Code와 Codex에서 쓸 수 있습니다.

## 하는 일

`/깊게 <요청>`이라고 쓰면 에이전트가 바로 작업하지 않고 다음 순서로 진행합니다.

1. **사전 질문 5개에 답합니다.**
   - 전문가 관점: 요청에 없어도 전문가라면 반드시 했을 일
   - 원자료: 먼저 확인할 1차 자료와 그 위치
   - 방법론·도구: 가장 맞는 방법과, 배제한 대안의 이유
   - 객관적 검증: 에이전트의 판단이 아닌 외부 기준 (공식 문서, 실행 결과, 원데이터 대조)
   - 완료 기준: 무엇이 확인되면 끝인가
2. **원래 요청을 더 깊은 프롬프트로 다시 씁니다.**
3. **그 프롬프트대로 작업합니다.** 비용이 들거나 외부에 나가는 작업이면 멈추고 확인을 받습니다.
4. **정한 검증을 실제로 실행하고** 완료 기준별로 충족·미충족을 보고합니다.

리서치, 보고서, 데이터 분석, 강의안, 자동화 설계, 코드 변경처럼 결과물 품질이 중요한 작업에 맞습니다. 간단한 질문이나 파일 한 개 수정에는 쓰지 않습니다.

## 설치

### 폴더 버전 (권장)

`깊게/` 폴더를 스킬 폴더에 복사합니다.

```bash
git clone https://github.com/MinJeJung/deep-mode-skill.git
cp -R deep-mode-skill/깊게 ~/.claude/skills/
```

Codex는 `~/.codex/skills/`에 복사합니다.

### 단일 파일 버전

`single-file/SKILL.md` 하나에 참고 자료를 부록으로 합쳐 두었습니다. `~/.claude/skills/깊게/SKILL.md` 위치에 저장하면 됩니다.

## 구성

| 파일 | 내용 |
|---|---|
| `깊게/SKILL.md` | 4단계 절차 본문 |
| `깊게/reference/task_type_checklists.md` | 작업 유형 판별표와 유형별 5문항 답 기준 |
| `깊게/reference/templates.md` | 단계별 출력 템플릿 |
| `깊게/reference/example.md` | 강의안 요청에 적용한 예시 |
| `깊게/agents/openai.yaml` | Codex 표시 정보 |
| `single-file/SKILL.md` | 위 내용을 합친 단일 파일 |

## 사용 예

```
/깊게 우리 팀 주간 매출 데이터를 분석해서 보고서로 만들어줘
/깊게 --확인 n8n으로 메일 자동 분류 워크플로를 설계해줘
```

`--확인`을 붙이면 다시 쓴 프롬프트를 보여 준 뒤 승인을 기다립니다.
